从语雀迁移到 YouMind

Nov 7, 2026 · 2 分钟阅读

语雀里的笔记可以导出成 Markdown。上一篇写的是用网页 Cookie 接 MCP，不必买超级会员的 Token。导出之后，文件还是停在磁盘上，Agent 要改一篇笔记，得再打开编辑器。

YouMind 把同一份东西放回一个能读的地方。看板下面是分组，分组里面是文档。标题单独占一行，正文是 Markdown。标题已经在外面，正文开头就不要再写一遍同名的一级标题。我把两篇导出的笔记写进同一个分组。打开分组，看到的是目录，不是一串平铺的文件。

给 Agent 的入口官方写在 OpenAPI 里：先装 YouMind skill，再用 @youmind-ai/cli。Skill 规定先搜接口、再看参数、再调用。CLI 做这三步，不必手写 HTTP。

npm install -g @youmind-ai/cli
npx skills add YouMind-OpenLab/skills --skill youmind
export YOUMIND_API_KEY=sk-ym-...
youmind search document
youmind info createDocument

密钥在 设置 → API Keys 创建，只放进 YOUMIND_API_KEY。不要写进仓库，也不要当成命令参数传进去。

我这次实际调用了两条。createDocument 收看板 id、标题和 Markdown 正文。moveFiles 再把文档移进分组，分组 id 放在 parentGroupId。之后用 listFiles 核对父级，用 getFile 看正文是不是真的写进去了。接口名不用猜，youmind search 能列出来，youmind info 能看到字段。

这份 OpenAPI 里没有 MCP。官方推荐的是 skill 加 CLI。同一套 /openapi/v1 可以被一个本地的 MCP 进程包住，密钥仍然只留在环境变量里，工具再去调创建、读取和移动。我这次没有走 MCP，写入和移动都是 CLI 完成的。

旧笔记里有一段还在用的数据库地址和口令。写进 YouMind 之前我换成了占位符。迁移搬的是正文，不是把凭据再复制一份。
